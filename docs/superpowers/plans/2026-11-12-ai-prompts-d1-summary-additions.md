# AI prompts D1: prompts summary additions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `GET {P}/ai/prompts-summary` what the web's Topics & Prompts page needs: last answer times on rows (B1), country, term and branded only scope (B2), a comparison with the period before (B4), weekly series per engine (B3) and per-entity cells (B5), with the opt-in parts costing nothing for callers that do not ask.

**Architecture:** Everything stays in the three summary modules (`summary_routes.py`, `summary.py`, `summary_repository.py`) and the summary models in `schemas/ai.py`. Each opt-in part is one more grouped query over `ai.observation_facts` (joined to `ai.entity_mentions` for B5), keyed by prompt and engine; topic rows are built in Python from the per-prompt results exactly as today, so no part adds a query per prompt. Parts not asked for are left out of the JSON (`Field(exclude_if=...)`), not sent as null.

**Tech Stack:** Python 3.13, FastAPI 0.142, Pydantic 2.13, SQLAlchemy 2 Core (async, asyncpg), PostgreSQL 18 with monthly partitions, pytest with Testcontainers, ruff, mypy strict, import-linter.

## Decisions

1. **Parameter names and defaults** (doc 19 section 3.7.9 scope names, section 2.5 window names):

   | Parameter | Type | Default | Meaning |
   |---|---|---|---|
   | `filter[country_iso]` | `^[A-Z]{2}$` | none | Prompts whose `country_iso` is this. A lower-case value is `422 validation_failed`. |
   | `filter[term]` | uuid | none | Prompts given the term or a term under it (the same rule as `GET {P}/prompts?filter[term]`, `keywords.trees.descendants`). |
   | `branded_only` | bool | `false` | Branded prompts alone. |
   | `compare` | `none` or `previous_period` | `none` | `previous_year`, `compare_from` and `compare_to` are not built: `previous_year` is `422 validation_failed`. |
   | `include` | comma list of `series`, `entities` | none | Opt-in blocks. Any other member is `422 validation_failed`. |

2. **Why `include` for B3 and B5 and `compare` apart.** One list parameter for optional blocks is how `GET .../tracked-keywords/{id}/rank-history?include=` already works (`ranks/routes.py`, `Commas`), so the web client and the docs know the shape. `compare` stays its own parameter because doc 19 section 2.5 defines it for every window read, and `compare_from`/`compare_to` will join it later. A block not asked for is absent from the JSON (`Field(default=None, exclude_if=_absent)`), so an existing caller's response and its query count are unchanged except for B1's two row fields and B2's `branded_only` echo, which every caller gets.
3. **`previous` with no data is null, never zero cells.** `previous` is null when the engine had no answer at all of the row's prompts in the comparison window (no fact row), so "no data" cannot be read as "0 of N". When there were answers but none valid, `previous` holds cells with denominator 0 and `value` null, as the current cells do. Topic rows: null when none of the topic's prompts had an answer there. `compare_window` (a `MetricWindow`) states the window once. No delta, interval or `is_detectable` is returned: that is slice 3 (paired tests); the web's interim unpaired check keeps working from the two sets of cells.
4. **`branded_only` with topic rows and strip counts.** `branded_only=true` keeps the branded prompts alone and wins over `include_branded` (doc 19 section 2.5 rule 7 and the 3.7.9 table). The response's `include_branded` says whether branded prompts were counted (`include_branded or branded_only`), and `branded_only` is echoed. Topic rows are built from the prompts in scope only, so with any scope parameter a topic row holds and counts only in-scope prompts, and a topic with none disappears; the web's strip, computed from the prompt rows, follows the same scope. Under `filter[term]` the topic rows are the term and the topic terms below it, with no row for prompts without a topic (a prompt of SOC that is also in Compliance does not bring a Compliance row into a SOC drill-down).
5. **Week boundary: Monday 00:00 in the project's timezone.** The AI schedules run Monday and Thursday at 01:00 project time for 8 hours (`B/ai/schedule.py`, `AI_SCHEDULE`). A project-local week holds exactly one Monday run and one Thursday run. UTC weeks would split them for any zone east of UTC: 01:00 on Monday in Asia/Kolkata (the Eventus project) is 19:30 UTC on Sunday, so the Monday run would land in the week before. Doc 19 section 2.5 says `week` is ISO, Monday start, and rule 1 says business dates are in the project timezone. The summary window is already project-local days.
6. **Maximum weeks and entities.** The series covers the request window, which is at most 92 days, so at most 14 points (checked for every weekday a window can start on, Task 4). Entity cells are given for at most `ENTITY_CELLS_MAX = 20` tracked entities: the own ones first, then competitors by name (the top-level `entities` list keeps listing all of them). The own brand is never cut. SEO allows 10 competitors; AI tracking has no limit, hence the cap.
7. **B1 is window-bound and follows the engine filter.** `last_observed_at` is the newest counted answer of the row in the window (current, not superseded), any status; `last_valid_at` the newest valid one; null when none. It comes from the same grouped query as the counts (two `max()` columns), so it costs no statement. No `meta.updated_at` (not needed by the page; the header reads the newest row value).
8. **B5 reads `ai.entity_mentions` rows that have a `mention_order`,** joined to the current fact row of a valid answer, for own and competitor entities alike. That is exactly the share of voice set `tracked_entities_mentioned` counts (`extraction/ai_facts.py`: only accepted own and competitor mentions, a product counted as its brand, get an order). `observation_facts.competitor_mentions` alone cannot give the own entities one by one (a project may own several brands), and one source keeps the cells consistent: an answer's entity shares add up to 1, and the own entities' shares add up to the row's `share_of_voice` numerator. Tests assert both. Per entity: `mentioned` over the row's valid answers (prompt weighted in topic rows, as `mentioned` is) and `share_of_voice` as `1 / tracked_entities_mentioned` for each answer that names it, over the answers that name a tracked entity (one answer one weight, also in topic rows). `metric_context` is unchanged: entity cells follow the `mentioned` and `share_of_voice` entries.
9. **Series content.** A point holds `week_start`, `mentioned`, `cited` and `share_of_voice`, over the week's answers inside the window (a week cut by `from` or `to` counts only its days in the window; the counts show it), weighted as the window's cells are. Every week the window touches gets a point, empty ones as zero counts with `value` null, so a chart has gaps, not missing x values. No `previous` on series or entity cells.
10. **OpenAPI.** `BT/api/test_openapi.py` fails whenever `backend/openapi/v1.json` is stale, so every task that changes the API regenerates it in its own commit (keeping each commit green), and Task 6 confirms it is current and writes the docs.

## Open points (recommended default in bold, applied by this plan)

1. **Series span.** **The series follows the request window** (28 days by default: 4 or 5 points). An 8-week sparkline beside a 28-day table needs a second read with `from` 55 days back and `include=series`. Alternative: a separate `series_weeks` parameter. Ask the owner only if the page wants both in one read.
2. **More than 20 tracked entities.** **Cut at 20, own first.** If a project ever tracks more, add `entity_ids` (doc 19 3.7.9 already names it) as a selector.
3. **Response size.** At full capacity (150 prompts, 3 engines, one topic, 28 days) `include=series,entities` with 11 entities is roughly 1.5 MB of JSON, and the API has no gzip middleware. **Recommend the web asks for `include` only together with `filter[term]` (the topic drawer) or for a small page,** and that gzip for the API is decided separately (not in this plan).
4. **B5's slice.** The gap analysis says B5 had no slice and proposed slice 2. **This plan builds it as Task 5 because the brief orders it;** dropping Task 5 leaves Tasks 1 to 4 and 6 intact.
5. **Last answer outside the window.** A prompt silent for the whole window shows `last_observed_at: null` even if it was answered before. **Recommended: the web reads null as "no answer in this window".** An all-time value would need an unbounded read across partitions.

## Traps (from plans A and B and their reviews; every one applies)

1. **Files are pure ASCII.** No em or en dashes, curly quotes, `x` signs or arrows in code, comments, docstrings, test names or commit messages. A test needing a non-ASCII input builds it with `chr()` (editing tools turn `\u` escapes into literal characters). Check before committing: `grep -nP '[^\x00-\x7F]' <files>` prints nothing.
2. **Edit with the file tools (Read, Edit, Write) only.** No shell heredocs, `sed -i` or replace scripts.
3. **asyncpg parameter types.** A parameter whose type PostgreSQL cannot infer needs a cast: `$4::text` when the same text parameter appears twice or beside a literal (see `_topic` in the summary tests), and `$2::uuid` inside `INSERT ... SELECT` (a select-list parameter is otherwise text and the insert fails with "is of type uuid but expression is of type text").
4. **A bound parameter in a GROUP BY expression.** SQLAlchemy renders each use of a bound value as its own `$n`, so `GROUP BY date_trunc('week', timezone($5, observed_at))` does not match the select list's `$3` and PostgreSQL says the column must appear in GROUP BY. Compute such a column in a subquery and group the outer query by the subquery column (Task 4 does).
5. **Partial indexes need their predicate.** `observation_facts_project_date_engine` and `entity_mentions_project_entity_observed` are `WHERE is_current`: a query must say `is_current` to use them.
6. **Partition pruning needs the instants on each partitioned table.** Every query bounds `observed_at` of each `ai.*` table it reads with the window's instants (`_window` does it for the facts; Task 5 repeats it for the mentions).
7. **ruff format, then mypy strict, then lint-imports.** `ruff check --fix` sorts imports. mypy strict rejects untyped defs and `Any` leaks in public signatures; a `**dict` splat into a Pydantic model is checked per field, so pass values, not dicts.
8. **Never stage another session's files.** Every commit below names its files. Commit messages carry no attribution lines and no dashes.
9. **`response.json()` of a `MetricCell`**: `numerator` is a float field, so `2` arrives as `2.0`; compare with `==` against ints (Python says `2.0 == 2`) and use `pytest.approx` for sums of fractions.

## Query plans and cost at full capacity

Capacity: 150 prompts, 3 engines, 2 answers a week. A 28-day window holds about 3,600 facts; the longest window (92 days) about 11,800.

- **B1:** two `max()` aggregates in the existing grouped query. No statement added.
- **B2:** filters on `ai.prompts` (`prompts_live_project` index) and one recursive CTE over `core.taxonomy_terms` under `filter[term]`; one `term_subtree` statement more, only under `filter[term]`. Every fact query then reads fewer prompts.
- **B4:** one more `counts_by_prompt` over the previous window: the same index scan on `observation_facts_project_date_engine (project_id, observed_date, engine_code) WHERE is_current`, pruned to that window's partitions, and a hash aggregate to at most 450 groups.
- **B3:** one statement: the same scan as `counts_by_prompt`, with the local week computed per row in a subquery, then a hash aggregate to at most 150 x 3 x 14 = 6,300 groups (1,800 to 2,250 at 28 days).
- **B5:** one statement: the facts scan as above, joined on the mentions' primary key `(observation_id, observed_at, entity_id, derivation_id)` with the mentions pruned to the window's partitions and `is_current`; at most 3,600 facts times the entities each names, aggregated to at most 150 x 3 x 20 = 9,000 groups.
- **No N+1:** topic rows, series points and entity cells are all built in Python from those dictionaries. `test_every_option_at_full_capacity_is_one_query_each` (Tasks 3 to 5) asserts that every option together adds at most 3 statements to the plain summary of a full project.
- **Python cost:** per topic and engine, the series loops weeks x prompts (3 x 14 x 150 = 6,300 lookups) and entity cells entities x prompts (3 x 20 x 150 = 9,000): milliseconds.

```python
def _last_answers(
    prompt_ids: Collection[UUID],
    engine_codes: Sequence[str],
    by_prompt: Mapping[tuple[UUID, str], Counts],
) -> tuple[datetime | None, datetime | None]:
    """When the newest counted answer of these prompts on these engines came, and the newest
    valid one; None when the window has none."""
    counted = [
        by_prompt[(prompt, code)]
        for prompt in prompt_ids
        for code in engine_codes
        if (prompt, code) in by_prompt
    ]
    observed = [c.last_observed_at for c in counted if c.last_observed_at is not None]
    valid = [c.last_valid_at for c in counted if c.last_valid_at is not None]
    return max(observed, default=None), max(valid, default=None)


def _prompt_row(
    prompt: SummaryPrompt,
    engine_codes: Sequence[str],
    by_prompt: Mapping[tuple[UUID, str], Counts],
```

```python
async def summary_prompts(
    db: AsyncSession,
    workspace_id: UUID,
    project_id: UUID,
    *,
    include_branded: bool,
    branded_only: bool = False,
    country_iso: str | None = None,
    term_id: UUID | None = None,
) -> list[SummaryPrompt]:
    """The project's active prompts (not archived), oldest first, with their topics. Branded
    prompts only with `include_branded`, or alone with `branded_only`; of one country; given
    `term_id` or a term under it (as the prompt list's `filter[term]`)."""
    p, v = ai_prompts.c, ai_prompt_versions.c
    statement = (
        select(p.id, v.text, p.is_branded)
        .join(
            ai_prompt_versions,
            and_(v.id == p.current_version_id, v.workspace_id == p.workspace_id),
        )
        .where(
            p.workspace_id == workspace_id,
            p.project_id == project_id,
            p.deleted_at.is_(None),
            p.is_active,
        )
        .order_by(p.created_at, p.id)
    )
    if branded_only:
        statement = statement.where(p.is_branded)
    elif not include_branded:
        statement = statement.where(~p.is_branded)
    if country_iso is not None:
        statement = statement.where(p.country_iso == country_iso)
    if term_id is not None:
        tagged = select(ai_prompt_terms.c.prompt_id).where(
            ai_prompt_terms.c.workspace_id == workspace_id,
            ai_prompt_terms.c.term_id.in_(
                descendants("term", [term_id], workspace_id, "term_tree")
            ),
        )
        statement = statement.where(p.id.in_(tagged))
    rows = list(await db.execute(statement))
    if not rows:
        return []
    topics = _topic_terms().subquery()
    assigned: dict[UUID, list[UUID]] = {}
    for row in await db.execute(
        select(topics.c.prompt_id, topics.c.term_id).where(
            topics.c.prompt_id.in_([row.id for row in rows])
        )
    ):
        assigned.setdefault(row.prompt_id, []).append(row.term_id)
    return [
        SummaryPrompt(
            id=row.id,
            text=row.text,
            is_branded=row.is_branded,
            topic_term_ids=tuple(sorted(assigned.get(row.id, []), key=str)),
        )
        for row in rows
    ]


async def term_subtree(db: AsyncSession, workspace_id: UUID, term_id: UUID) -> set[UUID]:
    """The term and every term under it, in the caller's workspace (none for another's)."""
    rows = await db.execute(descendants("term", [term_id], workspace_id, "term_tree"))
    return {row.id for row in rows}
```

```python
def _prompt_weighted(parts: Sequence[tuple[int, int]], n_observations: int) -> MetricCell:
    """The prompt weighted rate of a topic (docs/16 section 3, docs/17 section 4.1) from each
    prompt's (successes, valid answers): each prompt with a valid answer counts once, as
    successes / valid answers. The numerator is the sum of those rates, the denominator the
    number of such prompts, and `pooled` the answers."""
    rated = [(successes, valid) for successes, valid in parts if valid > 0]
    cell = _cell(
        sum(successes / valid for successes, valid in rated), len(rated), n_observations
    )
    return cell.model_copy(
        update={
            "pooled": Pooled(
                successes=sum(successes for successes, _ in rated),
                trials=sum(valid for _, valid in rated),
            )
        }
    )


def _weighted(members: Sequence[Counts], pick: Callable[[Counts], int]) -> MetricCell:
    return _prompt_weighted(
        [(pick(counts), counts.n_valid) for counts in members],
        sum(counts.n_observations for counts in members),
    )


def _prompt_cells(counts: Counts) -> EngineCells:
    """The cells of one prompt and engine: counts of answers."""
    valid, total = counts.n_valid, counts.n_observations
    return EngineCells(
        mentioned=_cell(counts.mentioned, valid, total),
        cited=_cell(counts.cited, valid, total),
        outcomes=OutcomeCells(
            mentioned_and_cited=_cell(counts.mentioned_and_cited, valid, total),
            mentioned_only=_cell(counts.mentioned_only, valid, total),
            cited_only=_cell(counts.cited_only, valid, total),
            neither=_cell(counts.neither, valid, total),
        ),
        share_of_voice=_cell(counts.sov_share, counts.sov_answers, total),
    )


def _topic_cells(members: Sequence[Counts]) -> EngineCells:
    """The cells of a topic and engine from the counts of the topic's prompts. Share of voice
    stays one answer one weight (docs/16 section 5), so it is the sum over the answers."""
    return EngineCells(
        mentioned=_weighted(members, lambda counts: counts.mentioned),
        cited=_weighted(members, lambda counts: counts.cited),
        outcomes=OutcomeCells(
            mentioned_and_cited=_weighted(members, lambda counts: counts.mentioned_and_cited),
            mentioned_only=_weighted(members, lambda counts: counts.mentioned_only),
            cited_only=_weighted(members, lambda counts: counts.cited_only),
            neither=_weighted(members, lambda counts: counts.neither),
        ),
        share_of_voice=_cell(
            sum(counts.sov_share for counts in members),
            sum(counts.sov_answers for counts in members),
            sum(counts.n_observations for counts in members),
        ),
    )


@dataclass(frozen=True, slots=True)
class _Read:
    """What the queries read, by prompt and engine. `previous` is None unless compared."""

    counts: Mapping[tuple[UUID, str], Counts]
    previous: Mapping[tuple[UUID, str], Counts] | None = None


def _engine_row(
    code: str, prompt_ids: Collection[UUID], read: _Read, *, topic: bool
) -> EngineSummary:
    """One engine's cells for a prompt row (`prompt_ids` holds the prompt alone) or a topic row
    (its prompts)."""

    def cells(members: Sequence[Counts]) -> EngineCells:
        if topic:
            return _topic_cells(members)
        return _prompt_cells(members[0] if members else _NONE)

    def found(source: Mapping[tuple[UUID, str], Counts]) -> list[Counts]:
        return [source[(prompt, code)] for prompt in prompt_ids if (prompt, code) in source]

    current = cells(found(read.counts))
    previous = None
    if read.previous is not None:
        # No answer in the window before is null, so no data is never read as a rate of 0.
        before = found(read.previous)
        previous = cells(before) if before else None
    return EngineSummary(
        engine_code=code,
        mentioned=current.mentioned,
        cited=current.cited,
        outcomes=current.outcomes,
        share_of_voice=current.share_of_voice,
        previous=previous,
    )


def _last_answers(
    prompt_ids: Collection[UUID],
    engine_codes: Sequence[str],
    by_prompt: Mapping[tuple[UUID, str], Counts],
) -> tuple[datetime | None, datetime | None]:
    """When the newest counted answer of these prompts on these engines came, and the newest
    valid one; None when the window has none."""
    counted = [
        by_prompt[(prompt, code)]
        for prompt in prompt_ids
        for code in engine_codes
        if (prompt, code) in by_prompt
    ]
    observed = [c.last_observed_at for c in counted if c.last_observed_at is not None]
    valid = [c.last_valid_at for c in counted if c.last_valid_at is not None]
    return max(observed, default=None), max(valid, default=None)


def _prompt_row(prompt: SummaryPrompt, engine_codes: Sequence[str], read: _Read) -> PromptSummaryRow:
    last_observed, last_valid = _last_answers([prompt.id], engine_codes, read.counts)
    return PromptSummaryRow(
        prompt_id=prompt.id,
        text=prompt.text,
        is_branded=prompt.is_branded,
        topic_term_ids=list(prompt.topic_term_ids),
        last_observed_at=last_observed,
        last_valid_at=last_valid,
        engines=[_engine_row(code, [prompt.id], read, topic=False) for code in engine_codes],
    )


def _topic_row(
    term_id: UUID | None,
    name: str | None,
    members: Collection[UUID],
    engine_codes: Sequence[str],
    read: _Read,
) -> TopicSummaryRow:
    last_observed, last_valid = _last_answers(members, engine_codes, read.counts)
    return TopicSummaryRow(
        term_id=term_id,
        name=name,
        prompt_count=len(members),
        last_observed_at=last_observed,
        last_valid_at=last_valid,
        engines=[_engine_row(code, members, read, topic=True) for code in engine_codes],
    )
```

```python
def _counts_columns(c: Any = _F) -> list[Any]:
    """The counts of the fact rows `c`: the facts table, or a subquery of all its columns."""
    valid = c.is_valid

    def count(*conditions: Any) -> Any:
        return func.count().filter(and_(*conditions))

    return [
        func.count().label("n_observations"),
        count(valid).label("n_valid"),
        count(valid, c.own_mentioned).label("mentioned"),
        count(valid, c.own_domain_cited).label("cited"),
        count(valid, c.own_mentioned, c.own_domain_cited).label("mentioned_and_cited"),
        count(valid, c.own_mentioned, ~c.own_domain_cited).label("mentioned_only"),
        count(valid, ~c.own_mentioned, c.own_domain_cited).label("cited_only"),
        count(valid, ~c.own_mentioned, ~c.own_domain_cited).label("neither"),
        count(valid, c.tracked_entities_mentioned >= 1).label("sov_answers"),
        # The own share of an answer is the sum of sov_o(e) over the own entities (docs/16

        # so the own entities are the tracked ones that are not competitors. A project may own

                    Float,

            0.0,
        ).label("sov_share"),
        func.max(c.observed_at).label("last_observed_at"),
```

```python
async def weekly_counts(
    db: AsyncSession,
    workspace_id: UUID,
    project_id: UUID,
    prompt_ids: Collection[UUID],
    *,
    since: datetime,
    until: datetime,
    engine_codes: Sequence[str] | None,
    timezone: str,
) -> dict[tuple[UUID, str, date], Counts]:
    """The counts by prompt, engine and week. A week starts on Monday at midnight in the
    project's timezone (docs/19 section 2.5, granularity `week`), the zone the Monday and
    Thursday schedules run in, so one week holds one run of each. The week is worked out in a
    subquery and grouped by its column there: grouped by the expression, its bound timezone
    would be a second parameter, which PostgreSQL reads as a different expression."""
    if not prompt_ids:
        return {}
    facts = (
        select(
            ai_observation_facts,
            cast(func.date_trunc("week", func.timezone(timezone, _F.observed_at)), Date).label(
                "week_start"
            ),
        )
        .where(*_window(workspace_id, project_id, prompt_ids, since, until, engine_codes))
        .subquery()
    )
    c = facts.c
    rows = await db.execute(
        select(c.prompt_id, c.engine_code, c.week_start, *_counts_columns(c)).group_by(
            c.prompt_id, c.engine_code, c.week_start
        )
    )
    return {(row.prompt_id, row.engine_code, row.week_start): _counts(row) for row in rows}
```

```python
async def entity_counts(
    db: AsyncSession,
    workspace_id: UUID,
    project_id: UUID,
    prompt_ids: Collection[UUID],
    entity_ids: Collection[UUID],
    *,
    since: datetime,
    until: datetime,
    engine_codes: Sequence[str] | None,
) -> dict[tuple[UUID, str, UUID], EntityCounts]:
    """Per prompt, engine and entity: the valid answers whose share of voice set holds the
    entity, and its share of each, 1 / the entities the set holds (docs/16 section 5). The set
    is the mentions with an order (`extraction.ai_facts`: accepted, own or competitor, a product
    counted as its brand), the same set `tracked_entities_mentioned` counts, so an answer's
    shares add up to 1 and the own entities' add up to the fact row's own share."""
    if not prompt_ids or not entity_ids:
        return {}
    m = ai_entity_mentions.c
    rows = await db.execute(
        select(
            _F.prompt_id,
            _F.engine_code,
            m.entity_id,
            func.count().label("mentioned"),
            func.sum(cast(literal(1), Float) / _F.tracked_entities_mentioned).label("sov_share"),
        )
        .select_from(
            ai_observation_facts.join(
                ai_entity_mentions,
                and_(
                    m.observation_id == _F.observation_id,
                    m.observed_at == _F.observed_at,
                    m.derivation_id == _F.derivation_id,
                    m.workspace_id == _F.workspace_id,
                ),
            )
        )
        .where(
            *_window(workspace_id, project_id, prompt_ids, since, until, engine_codes),
            _F.is_valid,
            _F.tracked_entities_mentioned >= 1,
            m.project_id == project_id,
            m.is_current,
            # The mentions' own partitions, bounded by the same instants.
            m.observed_at >= since,
            m.observed_at < until,
            m.mention_order.is_not(None),
            m.entity_id.in_(list(entity_ids)),
        )
        .group_by(_F.prompt_id, _F.engine_code, m.entity_id)
    )
    return {
        (row.prompt_id, row.engine_code, row.entity_id): EntityCounts(
            mentioned=row.mentioned, sov_share=float(row.sov_share)
        )
        for row in rows
    }
```

```python
class _Read:
    """What the queries read, by prompt and engine. `previous` is None unless compared, `weeks`
    None unless the series was asked for, `entity_ids` None unless the entity cells were."""

    counts: Mapping[tuple[UUID, str], Counts]
    previous: Mapping[tuple[UUID, str], Counts] | None = None
    weeks: Sequence[date] | None = None
    weekly: Mapping[tuple[UUID, str, date], Counts] = field(default_factory=dict)
    entity_ids: Sequence[UUID] | None = None

def _entity_cells(
    code: str, entity_id: UUID, prompt_ids: Collection[UUID], read: _Read, *, topic: bool
) -> EntityCells:
    parts = [
        (read.counts.get((prompt, code), _NONE), read.named.get((prompt, code, entity_id), _NOT_NAMED))
        for prompt in prompt_ids
    ]
    n_observations = sum(counts.n_observations for counts, _ in parts)
    if topic:
        mentioned = _prompt_weighted(
            [(named.mentioned, counts.n_valid) for counts, named in parts], n_observations
        )
    else:
        mentioned = _cell(
            sum(named.mentioned for _, named in parts),
            sum(counts.n_valid for counts, _ in parts),
            n_observations,
        )
    return EntityCells(
        entity_id=entity_id,
        mentioned=mentioned,
        share_of_voice=_cell(
            sum(named.sov_share for _, named in parts),
            sum(counts.sov_answers for counts, _ in parts),
            n_observations,
        ),
    )


def _engine_row(
    code: str, prompt_ids: Collection[UUID], read: _Read, *, topic: bool
) -> EngineSummary:
    """One engine's cells for a prompt row (`prompt_ids` holds the prompt alone) or a topic row
    (its prompts)."""

    def cells(members: Sequence[Counts]) -> EngineCells:
        if topic:
            return _topic_cells(members)
        return _prompt_cells(members[0] if members else _NONE)

    def found(source: Mapping[tuple[UUID, str], Counts]) -> list[Counts]:
        return [source[(prompt, code)] for prompt in prompt_ids if (prompt, code) in source]

    current = cells(found(read.counts))
    previous = None
    if read.previous is not None:
        # No answer in the window before is null, so no data is never read as a rate of 0.
        before = found(read.previous)
        previous = cells(before) if before else None
    series = None
    if read.weeks is not None:
        series = [
            _week(
                week,
                cells(
                    [
                        read.weekly[(prompt, code, week)]
                        for prompt in prompt_ids
                        if (prompt, code, week) in read.weekly
                    ]
                ),
            )
            for week in read.weeks
        ]
    entities = None
    if read.entity_ids is not None:
        entities = [
            _entity_cells(code, entity_id, prompt_ids, read, topic=topic)
            for entity_id in read.entity_ids
        ]
    return EngineSummary(
        engine_code=code,
        mentioned=current.mentioned,
        cited=current.cited,
        outcomes=current.outcomes,
        share_of_voice=current.share_of_voice,
        previous=previous,
        series=series,
        entities=entities,
    )
```
