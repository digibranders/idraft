# AI prompts D2: citations, fan-out queries, bulk run and bulk archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the web session the reads and writes the Citations page, the prompt inspector's Citations tab, the fan-out view and the bulk bar need: sources by registrable domain and by page with the citations behind them (B6), the ChatGPT fan-out queries already stored (B19), Run now for many prompts as one manual run, and archive or bring back many prompts in one call (B7).

**Architecture:** No migration and no new table. B6 and B19 are four `GET` routes under `{P}/ai` in new modules (`source_routes.py`, `sources.py`, `source_repository.py`, `schemas/ai_sources.py`); every read counts the same answers (valid, current, not superseded, of the prompts in scope) through one shared subquery, aggregates in one grouped statement, and pages by offset (aggregates) or keyset (the citation list). B7 adds `POST {P}/ai/runs` beside the other run triggers (`operations/run_routes.py`, `operations/runs.py`, `ai/run_repository.py`) and `POST {P}/prompts/bulk-archive` beside the prompt routes; their bodies live in a new `schemas/ai_bulk.py`. `schemas/ai.py` and the summary modules are not edited.

**Tech Stack:** Python 3.13, FastAPI 0.142, Pydantic 2.13, SQLAlchemy 2 Core (async, asyncpg), PostgreSQL 18 with monthly partitions, pytest with Testcontainers, ruff, mypy strict, import-linter.

## Decisions

1. **Domains are registrable domains, not hosts.** The handoff proposed one row per `domain_id` (a host). Doc 14 section 3 step 4 says "`www.` is kept in `host` and grouped by `registrable_domain`", and doc 16 C1 defines Source Share "with registrable domain d". `www.eventussecurity.com` and `eventussecurity.com` are one source. `GET {P}/ai/sources/domains` groups by `core.domains.registrable_domain`. A registrable domain whose citations carry different roles (an own path rule such as `acme.com/blog` while the rest of `acme.com` is third party, or an entity set changed inside the window) has one row per `(registrable_domain, domain_role, role_entity_id)`, so a row never mixes roles. Pages group by `(url_id, domain_role, role_entity_id)`; the drill-down filter is `filter[registrable_domain]`, not `filter[domain_id]`.
2. **One scope for every read, so a row and its drill-down agree.** All four routes take `from`, `to` (project-local dates, both included, default the 28 days ending today, at most 92: `422 window_too_large`, `from` after `to` is `422 validation_failed`; the summary's `summary_dates`), `filter[engine_code_in]`, `filter[prompt_id]`, `filter[term]` (the term or one under it) and `include_branded` (default false). An answer counts when its current fact row is valid, it is not superseded and its prompt is active and not branded (branded too with `include_branded`), exactly the summary's answers (doc 16 rule 3 and rule 4). `filter[prompt_id]` names one prompt and wins over the active and branded rules: the inspector shows the sources of an archived or a branded prompt too. A refusal's citations never count (the handoff's "a citation of an invalid answer is left out").
3. **Citation unit** = a distinct `(observation_id, url_id)` (doc 16 section 7, C2). Ingest writes one citation row per canonical URL per answer (`ai_parse._Sources` keys on the URL hash), but nothing in the table enforces it, so the count is `count(DISTINCT (observation_id, url_id))`; `occurrences` never counts.
4. **Source share.** `source_share` is a `MetricCell`: numerator the row's units, denominator every unit in scope, `n_observations` the valid answers in scope. `filter[domain_role_in]` narrows the rows, never the denominator (C1 is a share of all sources). `meta` gives `answers`, `answers_citing`, `citation_units` and `by_role` (units and citing answers for own, competitor and third party, always all three) for the strip (CI-01, CI-04).
5. **Engines on rows.** Each row carries `engines: [{engine_code, citation_units}]` over `meta.engine_codes`: the `filter[engine_code_in]` engines, else the three slice 1 engines (not the project's enabled ones, so an engine turned off with answers in the window still shows its share). One grouped statement: a filtered count per engine.
6. **Pagination.** The aggregates (`sources/domains`, `sources/pages`, `fanout-queries`) page by **offset** with `page.total` (the repository's `Offset`, default 50, at most 200): the total is the number of distinct domains or pages (CI-04) and a sorted aggregate has no stable keyset. Doc 19 says cursor for these; the as built note says offset. The citation list keeps doc 19's keyset `(observed_at DESC, observation_id DESC, citation_index)` with a cursor bound to its filters (`400 invalid_cursor` otherwise).
7. **Sorts.** Domains and pages: `sort` = `-citation_units` (default), `-observations`, `-prompts`; ties by units, then registrable domain or canonical URL, role and entity, so a page boundary never moves. `-trend` (doc 19) needs a series and is not built.
8. **New markers: `compare=previous_period`** (default `none`) on domains and pages adds `previous: {citation_units, observations}` to each row, counted over as many local days just before the window, `0` when the source was not cited there (doc 16 C5: new = at least 2 units now and 0 before), plus `meta.compare_window` and `meta.previous_answers` (the valid answers there; `0` means the previous window has no data, so a zero `previous` is "no answer", not "not cited"). Not asked, `previous`, `compare_window` and `previous_answers` are absent from the JSON. A "Lost" list (sources cited before and not now, C6) is not a row of the current window and is not built (Open point 1).
9. **Fan-out completeness: the stored list against `fanout_count`, not the `truncated` flag.** The handoff said a list is complete exactly when `truncated` is absent. The code says otherwise: `ai_parse._bounded` halves the list with the most items (any of `brand_entities`, `fan_out_queries`, `ads`) until the extras fit 16 KB and then sets `truncated: true`, so `truncated` is also set when only the ads were cut; when halving every list is not enough it stores `{"truncated": true}` and the fan-out list is gone. A cut list keeps the provider's first queries (a prefix). `ai.observations.fanout_count` is the length before bounding (capped at 32,767 at ingest). So an answer's list is complete exactly when `jsonb_array_length(provider_extras->'fan_out_queries') = fanout_count`; `meta.answers_truncated` counts the answers where it is shorter, and their missing queries are in no row. Task 4 has a test that builds extras over the bound through the real parser, stores them (the 16 KB check constraint must accept what the parser kept) and checks that Python's byte count equals PostgreSQL's `octet_length(provider_extras::text)`.
10. **Fan-out rows.** Grouped by `normalized_text` (lower case, trimmed, inner whitespace one space, in SQL: `lower(btrim(regexp_replace(q, '\s+', ' ', 'g')))`) and engine; `query_text` is the most common spelling (`mode()`); `observations` counts answers (a query repeated in one answer counts once); `prompts` and `prompt_ids` (the web's topic clusters, FO-11); `first_seen_at`, `last_seen_at`; `cited_domains`: the 5 registrable domains with the most citation units in the answers that issued the query, worded as an association (which query found which source is not stored). `min_support` (default 2, 1 to 1,000) drops rarer queries. Engines: the engines that expose fan-out (`ENGINES[...].exposes_fanout`: ChatGPT); `filter[engine_code_in]` naming another is `422 engine_has_no_fanout` with `engine_codes`; `meta.engines_without_fanout` lists the others so the web says "not exposed", never zero.
11. **Bulk run: `POST {P}/ai/runs`, one run for up to 150 prompts.** Body `{ prompt_ids: uuid[] (1 to 150, repeats dropped), engine_codes?: EngineCode[] (1 to 3) }`, `runs:trigger`, `202` with `{ data: Run, meta: { prompts, answers, estimated_cost_usd, skipped, manual_runs_today } }`. It is ONE manual run against the 20 a day limit and its tasks count against `max_ai_observations_per_month`, with run-now's errors and run-now's planning path (standard queue, the worker plans it within a minute, a budget used up makes it `budget_blocked` when planned, `503 provider_paused` while the provider is paused). In the order checked: `503 provider_paused`; `404` for a deleted or unknown project; `422 validation_failed` `prompt_unknown` at `prompt_ids` when any id is not an active prompt of the project (archived, deleted, of another project: the whole request, as `check-now` does with `keyword_unknown`); `422 engine_not_enabled` at `engine_codes` per named engine the planner cannot ask (not on, or off in the catalogue); without `engine_codes`, every engine the project has on; then, under the manual run lock, what is left out: the planner's own skips (`prompt_too_long`, `location_not_enabled`) and every asked engine of a prompt that has an answer on its way on one of them (`check_pending` for the pending pairs, `prompt_pending` for the same prompt's other engines: the run's selector is `prompt_ids` times `engine_codes`, so a prompt cannot be asked on some engines only); nothing left is `409 check_pending` (with `prompt_ids` and `skipped`) when something was pending, else `422 nothing_to_run` (with `skipped`); then `422 price_unavailable`; then `429 manual_run_limit`; then `422 quota_exceeded` (`requested` = the tasks this run makes). Price is checked after the pending check here (run-now checks it before), because the estimate is of what is left. `meta.skipped` lists every pair left out with its reason.
12. **Bulk run cap and the planner.** The planner refuses a manual run naming more than `MANUAL_PROMPTS_MAX = 100` prompts with a `ValueError` at plan time (`collectors/ai_prompt.py`), which would fail a valid 150 prompt run after its `202`. Task 5 sets `MANUAL_PROMPTS_MAX = BASE_PLAN.max_prompts` (150) and the body's cap reads the same value: a bulk run can name every active prompt of the base plan.
13. **Bulk run idempotency.** No `Idempotency-Key` (as run-now and check-now). The manual run lock and the pending check stop a second paid request: a double click makes one `202` and `409 check_pending` for the rest (the first run is `planned` and names the prompts). The pending check now reads `pending_pairs` for every prompt in one statement for tasks and one for planned runs; `pending_engines` (run-now) delegates to it.
14. **Bulk archive: `POST {P}/prompts/bulk-archive`, ids only.** Body `{ ids: uuid[] (1 to 1,000), archive: boolean }`, `prompts:write`, `200 { data: { matched, updated } }` (the tracked keyword route's shape and models). `matched` = the project's live prompts among `ids` (ids of another project, deleted or unknown are not matched, as the tracked keyword route does); `updated` = those whose state changed. It follows `DELETE` and `PATCH is_active` exactly: answers, versions and terms stay; no new version; a prompt brought back is not checked against the engines' countries again; bringing back counts against `max_active_prompts`, all or none (`422 quota_exceeded` with `limit`, `used`, `requested`), under the workspace's prompt write lock so two requests cannot both take the last places. One transaction: no partial failure. Audit: one `prompt.bulk_changed` on the project (`is_active`, `matched`, `changed`) and one `prompt.archived` (archive) or `prompt.updated` (bring back) per changed prompt with `before`/`after` `is_active` and `bulk: true`. `filter` (doc 19) is not built (Open point 2); `panel_locked` does not apply until panels exist.
15. **Module placement.** New schema modules `schemas/ai_sources.py` and `schemas/ai_bulk.py`; the bulk run route goes in `operations/run_routes.py` (beside check-now and keyword metrics refresh) with the `ai` tag added; the bulk archive route in `ai/prompt_routes.py`. `main.py` and `resources.py` gain one service and one router (small, additive).
16. **OpenAPI.** `BT/api/test_openapi.py` fails on a stale `backend/openapi/v1.json`, so every task that changes the API regenerates it in its own commit (`uv run python -m idraft.api.openapi > openapi/v1.json` from `backend/`).

## Open points (recommended default in bold, applied by this plan)

1. **Lost sources (C6).** **Not built.** A source cited before and not now is not a row of the current window. Recommended later: doc 19's `GET {P}/ai/sources/changes?kind=new|lost&min_support=2` (Phase 13). The web shows "New" from `previous` and leaves "Lost" out until then.
2. **Bulk archive by filter.** **`ids` only.** The Prompts tab holds every active prompt's id (at most 150 in the summary), so "Select all N matching" can send ids. A `filter` body (doc 19, as the tracked keyword route has) can follow with saved views (B8).
3. **When to build `ai.daily_domain_citations`.** **Not now.** A 28 day window of a full project is about 3,600 answers. Recommended trigger: once a real project has a month of answers, run the domains read under `EXPLAIN (ANALYZE, BUFFERS)` (Task 1 Step 9 gives the query) and build the rollup when it passes 1 s.
4. **A prompt pending on one engine is left out on all of them** (Decision 11). **Accepted:** during a schedule window every engine of a prompt is usually pending together, so little is lost, and the alternative (a selector with excluded pairs) changes the planner and the month's count. Recommended to revisit only if the web reports `prompt_pending` often.
5. **`url_id` is a JSON integer** on page and citation rows (an `observation_id` is a string, doc 19 `BigId`). **Accepted:** `core.urls` ids are a sequence far below 2^53. Change both to strings only if a client in another language needs it.
6. **Quote per citation (CI-11).** **Not checked, not built**, as the handoff says (section 7).

## Traps (from plans A, B and D1 and their reviews; every one applies)

1. **Files are pure ASCII.** No em or en dashes, curly quotes, `x` signs or arrows in code, comments, docstrings, test names or commit messages. A test needing a non-ASCII input builds it with `chr()` (editing tools turn `\u` escapes into literal characters). Check before committing: `grep -nP '[^\x00-\x7F]' <files>` prints nothing.
2. **Edit with the file tools (Read, Edit, Write) only.** No shell heredocs, `sed -i` or replace scripts.
3. **asyncpg parameter types.** A parameter PostgreSQL cannot type needs a cast: `$3::text` when the same text parameter appears twice, `$10::jsonb` for a JSON text, `$2::uuid` inside `INSERT ... SELECT`, `$3::bigint[]` for an id array.
4. **A bound parameter in a GROUP BY expression** renders as a new `$n` at each use, so PostgreSQL says the column must appear in GROUP BY. Compute such a column (the normalized fan-out text) in a subquery and group the outer query by the subquery column (Task 4 does).
5. **Partial indexes need their predicate.** `observation_facts_project_date_engine` is `WHERE is_current`: the counted answers say `is_current`.
6. **Partition pruning needs the instants on each partitioned table.** `counted_answers` bounds `observed_at` of the facts and of the observations; every read of `ai.citations` adds the same bounds on `ai.citations.observed_at`. The facts' `observed_date` is bounded a day either side (it is the answer's UTC date).
7. **One `counted_answers` per statement.** `filter[term]` adds a recursive CTE named `term_tree`; two counted subqueries in one statement would define it twice. Every statement here has one.
8. **ruff format, then mypy strict, then lint-imports.** `ruff check --fix` sorts imports. mypy strict rejects untyped defs and `Any` leaks in public signatures; a value from a `Literal` field read out of the database is `str` to mypy: `cast(DomainRole, ...)` it.
9. **Never stage another session's files.** Every commit below names its files. Commit messages carry no attribution lines and no dashes.
10. **`MetricCell.numerator` is a float field:** `4` arrives as `4.0`; compare with `==` against ints.
11. **The cross-tenant list scan** treats any JSON integer equal to the other tenant's observation or SERP snapshot id (small integers on a fresh database) as a leak, `page` counts excepted. Tenant A's counts in the new lists are 0 or 1 by construction (one answer, one citation); do not seed more answers for the tenants.
12. **Every new route is declared in `BT/api/test_route_access.py` `EXPECTED`** (method, path, permission) and every new mutating route has a body in `BT/security/test_cross_tenant.py` `BODIES` (`test_every_route_is_scoped_by_a_workspace_or_accounted_for` compares the sets).
13. **Unknown query parameters are refused** (`pagination.reject_unknown_query`): a route reads only the parameters it declares, including those of its dependencies, so the shared scope is a dependency function, not `request.query_params`.
14. **Date expectations** assume the run does not cross UTC midnight, as the summary tests do; the test projects use the default `UTC` timezone.

## Query plans and cost at full capacity

Capacity: 150 prompts, 3 engines, 2 answers a week: about 3,600 answers in 28 days, 11,800 in 92. ChatGPT and Gemini answers cite 5 to 15 pages; an AI Mode answer can list a few hundred.

- **Counted answers** (every read): an index scan of `observation_facts_project_date_engine (project_id, observed_date, engine_code) WHERE is_current` over the window's partitions, joined on the observations' primary key `(id, observed_at)` for `superseded_by`, with the prompt scope as a semi-join on `ai.prompts` (at most 150 rows).
- **Domains and pages:** the counted answers joined to `ai.citations` on its primary key prefix `(observation_id, observed_at)`, pruned to the window's partitions, then to `core.domains` (and `core.urls`) by primary key, and one hash aggregate. At 28 days that is about 36,000 citation rows at 10 a answer, and about 1,000,000 if every answer listed 300; `count(DISTINCT ...)` sorts within each group. Statements: project zone 1, rows 1 (the total is `count(*) OVER ()` in the same statement), totals 2 (the answer count and units by role with `ROLLUP`); one more only for a page past the end; `compare` adds 2. Task 1 asserts that a full project (3,600 answers, 36,000 citations) reads exactly as many statements as a small one.
- **Citation list:** one keyset statement (`ORDER BY observed_at DESC, observation_id DESC, citation_index LIMIT n + 1`) over the same join; a page of 50 stops early.
- **Fan-out:** one statement for rows (a `jsonb_array_elements_text` lateral unnest of the counted ChatGPT answers, about 1,200 a month with a handful of queries each, normalized in a subquery, then a hash aggregate), one for the top 5 domains of the page's queries (the answers that issued them joined to their citations, ranked with `row_number()`), one for the totals.
- **Bulk run:** a fixed number of statements whatever the number of prompts: the prompts (1), the engines (1), the planner's selection (3), the lock, the pending tasks and the planned runs (2), the price book (1), the day's manual runs (1), the quota row and the month's tasks (3), the insert and the audit entry. Task 5 asserts that 150 prompts read as many statements as 1.
- **Bulk archive:** the lock, one `SELECT ... FOR NO KEY UPDATE` of the rows, the quota (2, bringing back only), one `UPDATE`, two audit inserts (at most `ROWS_PER_STATEMENT` per insert).

Optional check after Task 4 (not a gate): with `full_project` seeded, run the domains statement (log it with `statements`) under `EXPLAIN (ANALYZE, BUFFERS)` and confirm that only the window's partitions of `ai.observation_facts`, `ai.observations` and `ai.citations` appear.

@contextmanager
def statements(resources: Resources) -> Iterator[list[str]]:
    """The SQL statements the API sends while the block runs."""
    seen: list[str] = []

    def record(*args: Any) -> None:
        seen.append(args[2])

    engine = resources.engine.sync_engine
    event.listen(engine, "before_cursor_execute", record)
    try:
        yield seen
    finally:
        event.remove(engine, "before_cursor_execute", record)

```python
"""Reads of cited sources and fan-out queries (docs/16 sections 7 and 9; plan D2). Row-level
security keeps every read in the caller's workspace; each query names the workspace and the
project as well.

An answer counts when its prompt is in scope, its current fact row says it is valid and it is
not superseded (docs/16 rule 3), as in the prompts summary; only the citations and fan-out
queries of counted answers are read. Every query bounds `observed_at` of each `ai.*` table it
reads with the window's instants, so the partitions of other months are not read. Sources are
aggregated by query: `ai.daily_domain_citations` is not built, and a 28 day window of a full
project is about 3,600 answers."""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from datetime import UTC, date, datetime, timedelta
from typing import Any, Final
from uuid import UUID

from sqlalchemy import Select, and_, desc, func, literal_column, select, tuple_
from sqlalchemy.ext.asyncio import AsyncSession

from idraft.db.tables import (
    ai_citations,
    ai_observation_facts,
    ai_observations,
    ai_prompt_terms,
    ai_prompts,
    domains,
)
from idraft.keywords.trees import descendants

_F, _O, _C, _D = ai_observation_facts.c, ai_observations.c, ai_citations.c, domains.c
ROLES: Final = ("own", "competitor", "third_party")
# The sorts of the source routes and the output column each orders by.
SORT_COLUMNS: Final = {
    "-citation_units": "citation_units",
    "-observations": "observations",
    "-prompts": "prompts",
}


@dataclass(frozen=True, slots=True)
class SourceScope:
    """Which answers a read counts: the project's, in [since, until), on these engines."""

    workspace_id: UUID
    project_id: UUID
    since: datetime
    until: datetime
    engine_codes: tuple[str, ...]
    include_branded: bool = False
    prompt_id: UUID | None = None
    term_id: UUID | None = None


@dataclass(frozen=True, slots=True)
class Counted:
    """What one group of citations holds."""

    citation_units: int
    observations: int
    prompts: int
    # In the order of the scope's engines.
    engine_units: tuple[int, ...]
    first_seen_at: datetime
    last_seen_at: datetime


@dataclass(frozen=True, slots=True)
class DomainCount:
    registrable_domain: str
    domain_role: str
    role_entity_id: UUID | None
    counted: Counted


@dataclass(frozen=True, slots=True)
class Totals:
    answers: int
    answers_citing: int
    citation_units: int
    # Each role: its citation units and the answers that cite a source of it.
    by_role: dict[str, tuple[int, int]]


def _shifted(instant: datetime, days: int) -> date:
    """The UTC date of `instant`, moved by `days`; the calendar's ends stay where they are."""
    day = instant.astimezone(UTC).date()
    try:
        return day + timedelta(days=days)
    except OverflowError:
        return day


def _prompts_in_scope(scope: SourceScope) -> Select[tuple[UUID]]:
    """The prompts whose answers count: with `prompt_id` that prompt alone, archived or branded
    (the inspector shows any prompt's sources); else the active prompts, the branded ones only
    with `include_branded`. `term_id` keeps those given the term or a term under it."""
    p = ai_prompts.c
    statement = select(p.id).where(
        p.workspace_id == scope.workspace_id,
        p.project_id == scope.project_id,
        p.deleted_at.is_(None),
    )
    if scope.prompt_id is not None:
        statement = statement.where(p.id == scope.prompt_id)
    else:
        statement = statement.where(p.is_active)
        if not scope.include_branded:
            statement = statement.where(~p.is_branded)
    if scope.term_id is not None:
        tagged = select(ai_prompt_terms.c.prompt_id).where(
            ai_prompt_terms.c.workspace_id == scope.workspace_id,
            ai_prompt_terms.c.term_id.in_(
                descendants("term", [scope.term_id], scope.workspace_id, "term_tree")
            ),
        )
        statement = statement.where(p.id.in_(tagged))
    return statement


def counted_answers(scope: SourceScope) -> Any:
    """The counted answers, one row each: `observation_id`, `observed_at`, `prompt_id`,
    `engine_code`, and for the fan-out reads `fanout_count` and the stored `fan_out` list."""
    return (
        select(
            _F.observation_id,
            _F.observed_at,
            _F.prompt_id,
            _F.engine_code,
            _O.fanout_count,
            _O.provider_extras["fan_out_queries"].label("fan_out"),
        )
        .select_from(
            ai_observation_facts.join(
                ai_observations,
                and_(
                    _O.id == _F.observation_id,
                    _O.observed_at == _F.observed_at,
                    _O.workspace_id == _F.workspace_id,
                ),
            )
        )
        .where(
            _F.workspace_id == scope.workspace_id,
            _F.project_id == scope.project_id,
            _F.is_current,
            _F.is_valid,
            _F.observed_at >= scope.since,
            _F.observed_at < scope.until,
            # A fact's date is its answer's UTC date: a day either side of the instants is safe,
            # and it is what the (project, date, engine) index is searched with.
            _F.observed_date >= _shifted(scope.since, -1),
            _F.observed_date <= _shifted(scope.until, 1),
            _F.engine_code.in_(list(scope.engine_codes)),
            _F.prompt_id.in_(_prompts_in_scope(scope)),
            _O.workspace_id == scope.workspace_id,
            _O.project_id == scope.project_id,
            _O.observed_at >= scope.since,
            _O.observed_at < scope.until,
            _O.superseded_by.is_(None),
        )
        .subquery("counted")
    )


def citation_bounds(scope: SourceScope) -> list[Any]:
    """The conditions that keep `ai.citations` to the project and the window's partitions."""
    return [
        _C.workspace_id == scope.workspace_id,
        _C.project_id == scope.project_id,
        _C.observed_at >= scope.since,
        _C.observed_at < scope.until,
    ]


def _cited(scope: SourceScope) -> tuple[Any, Any]:
    """The counted answers, and those answers joined to their citations and cited domains."""
    answers = counted_answers(scope)
    source = answers.join(
        ai_citations,
        and_(
            _C.observation_id == answers.c.observation_id,
            _C.observed_at == answers.c.observed_at,
        ),
    ).join(domains, _D.id == _C.domain_id)
    return answers, source


def unit() -> Any:
    """One citation unit: a URL of an answer (docs/16 C2), counted once however often listed."""
    return tuple_(_C.observation_id, _C.url_id).distinct()


def _measures(answers: Any, scope: SourceScope) -> list[Any]:
    return [
        func.count(unit()).label("citation_units"),
        func.count(_C.observation_id.distinct()).label("observations"),
        func.count(answers.c.prompt_id.distinct()).label("prompts"),
        *(
            func.count(unit()).filter(answers.c.engine_code == code).label(f"units_{index}")
            for index, code in enumerate(scope.engine_codes)
        ),
        func.min(_C.observed_at).label("first_seen_at"),
        func.max(_C.observed_at).label("last_seen_at"),
    ]


def _counted(row: Any, scope: SourceScope) -> Counted:
    values = row._mapping
    return Counted(
        citation_units=row.citation_units,
        observations=row.observations,
        prompts=row.prompts,
        engine_units=tuple(values[f"units_{index}"] for index in range(len(scope.engine_codes))),
        first_seen_at=row.first_seen_at,
        last_seen_at=row.last_seen_at,
    )


def order_by(sort: str, *keys: Any) -> list[Any]:
    """The sort's column, then units, then the row's keys: a page boundary never moves."""
    return [desc(literal_column(SORT_COLUMNS[sort])), desc(literal_column("citation_units")), *keys]


async def page_of(
    db: AsyncSession, grouped: Select[Any], order: Sequence[Any], *, offset: int, limit: int
) -> tuple[list[Any], int]:
    """A page of grouped rows and how many groups there are: the count comes with the rows
    (`count(*) OVER ()`), and is read on its own only for a page past the end."""
    rows = (
        await db.execute(
            grouped.add_columns(func.count().over().label("total"))
            .order_by(*order)
            .offset(offset)
            .limit(limit)
        )
    ).all()
    if rows:
        return list(rows), int(rows[0].total)
    if offset == 0:
        return [], 0
    total = (await db.execute(select(func.count()).select_from(grouped.subquery()))).scalar_one()
    return [], int(total)


async def domain_counts(
    db: AsyncSession,
    scope: SourceScope,
    *,
    roles: Sequence[str] | None,
    sort: str,
    offset: int,
    limit: int,
) -> tuple[list[DomainCount], int]:
    """A page of sources by (registrable domain, role, entity), and how many there are."""
    answers, source = _cited(scope)
    keys = (_D.registrable_domain, _C.domain_role, _C.role_entity_id)
    grouped = (
        select(*keys, *_measures(answers, scope))
        .select_from(source)
        .where(*citation_bounds(scope))
        .group_by(*keys)
    )
    if roles:
        grouped = grouped.where(_C.domain_role.in_(list(roles)))
    rows, total = await page_of(
        db,
        grouped,
        order_by(
            sort, _D.registrable_domain, _C.domain_role, _C.role_entity_id.asc().nulls_first()
        ),
        offset=offset,
        limit=limit,
    )
    return [
        DomainCount(
            registrable_domain=row.registrable_domain,
            domain_role=row.domain_role,
            role_entity_id=row.role_entity_id,
            counted=_counted(row, scope),
        )
        for row in rows
    ], total


async def answer_count(db: AsyncSession, scope: SourceScope) -> int:
    """The counted answers, citing or not."""
    answers = counted_answers(scope)
    count: int = (await db.execute(select(func.count()).select_from(answers))).scalar_one()
    return count


async def totals(db: AsyncSession, scope: SourceScope) -> Totals:
    """The counted answers, and every citation unit in scope in all and by role (one `ROLLUP`
    statement: the row without a role is the whole)."""
    answers_in_scope = await answer_count(db, scope)
    _, source = _cited(scope)
    rows = await db.execute(
        select(
            _C.domain_role,
            func.count(unit()).label("units"),
            func.count(_C.observation_id.distinct()).label("observations"),
        )
        .select_from(source)
        .where(*citation_bounds(scope))
        .group_by(func.rollup(_C.domain_role))
    )
    by_role = {role: (0, 0) for role in ROLES}
    units = citing = 0
    for row in rows:
        if row.domain_role is None:
            units, citing = row.units, row.observations
        else:
            by_role[row.domain_role] = (row.units, row.observations)
    return Totals(
        answers=answers_in_scope, answers_citing=citing, citation_units=units, by_role=by_role
    )

@dataclass(frozen=True, slots=True)
class SourceQuery:
    """The scope parameters every source route takes."""

    start: date | None = None
    end: date | None = None
    engine_codes: Sequence[EngineCode] | None = None
    include_branded: bool = False
    prompt_id: UUID | None = None
    term_id: UUID | None = None
    roles: Sequence[DomainRole] | None = None


@dataclass(frozen=True, slots=True)
class Scoped:
    """A request's scope, with its window as local days and as the answer states it."""

    scope: SourceScope
    window: MetricWindow
    first: date
    last: date
    zone: ZoneInfo


def out_of_range(field: str) -> RequestValidationError:
    return RequestValidationError(
        [{"loc": ("query", field), "type": "out_of_range", "msg": f"`{field}` is out of range."}]
    )


def local_instants(first: date, last: date, zone: ZoneInfo) -> tuple[datetime, datetime]:
    try:
        return instants(first, last, zone)
    except (OverflowError, ValueError):
        raise out_of_range("to") from None


def shown_engines(asked: Sequence[EngineCode] | None) -> list[str]:
    """The engines a read counts: those asked for, else the three of slice 1, in code order."""
    return sorted({str(code) for code in (asked or list(EngineCode))})


async def scoped(
    db: AsyncSession,
    access: WorkspaceAccess,
    project_id: UUID,
    query: SourceQuery,
    engines: Sequence[str],
) -> Scoped:
    """The request's scope in the project's timezone; `404` for a deleted or unknown project."""
    zone_row = await project_zone(db, access.workspace_id, project_id)
    if zone_row is None:
        raise NotFoundError
    zone = ZoneInfo(zone_row.timezone)
    first, last = summary_dates(query.start, query.end, datetime.now(zone).date())
    since, until = local_instants(first, last, zone)
    return Scoped(
        scope=SourceScope(
            workspace_id=access.workspace_id,
            project_id=project_id,
            since=since,
            until=until,
            engine_codes=tuple(engines),
            include_branded=query.include_branded,
            prompt_id=query.prompt_id,
            term_id=query.term_id,
        ),
        window=MetricWindow(
            from_=first.isoformat(), to=last.isoformat(), timezone=zone_row.timezone
        ),
        first=first,
        last=last,
        zone=zone,
    )


def engine_units(counted: Counted, engines: Sequence[str]) -> list[EngineUnits]:
    return [
        EngineUnits(engine_code=EngineCode(code), citation_units=units)
        for code, units in zip(engines, counted.engine_units, strict=True)
    ]


def share(units: int, totals: Totals) -> MetricCell:
    """A source's units over every unit in scope (docs/16 C1)."""
    whole = totals.citation_units
    return MetricCell(
        value=None if whole == 0 else units / whole,
        numerator=units,
        denominator=whole,
        n_observations=totals.answers,
    )


def sources_meta(
    now: Scoped, query: SourceQuery, engines: Sequence[str], totals: Totals
) -> SourcesMeta:
    return SourcesMeta(
        window=now.window,
        include_branded=query.include_branded,
        engine_codes=[EngineCode(code) for code in engines],
        answers=totals.answers,
        answers_citing=totals.answers_citing,
        citation_units=totals.citation_units,
        by_role=[
            RoleUnits(domain_role=cast(DomainRole, role), citation_units=units, observations=seen)
            for role, (units, seen) in totals.by_role.items()
        ],
    )


class SourceService:
    def __init__(self, *, sessions: async_sessionmaker[AsyncSession]) -> None:
        self._sessions = sessions

    def _transaction(self, access: WorkspaceAccess) -> AbstractAsyncContextManager[AsyncSession]:
        return workspace_transaction(self._sessions, access.workspace_id, user_id=access.user_id)

    async def domains(
        self,
        access: WorkspaceAccess,
        project_id: UUID,
        query: SourceQuery,
        *,
        sort: SourceSort,
        page: OffsetParams,
    ) -> SourceDomainPage:
        engines = shown_engines(query.engine_codes)
        async with self._transaction(access) as db:
            now = await scoped(db, access, project_id, query, engines)
            rows, total = await repository.domain_counts(
                db, now.scope, roles=query.roles, sort=sort, offset=page.offset, limit=page.limit
            )
            whole = await repository.totals(db, now.scope)
        return SourceDomainPage(
            data=[
                SourceDomainRow(
                    registrable_domain=row.registrable_domain,
                    domain_role=cast(DomainRole, row.domain_role),
                    role_entity_id=row.role_entity_id,
                    citation_units=row.counted.citation_units,
                    observations=row.counted.observations,
                    prompts=row.counted.prompts,
                    engines=engine_units(row.counted, engines),
                    source_share=share(row.counted.citation_units, whole),
                    first_seen_at=row.counted.first_seen_at,
                    last_seen_at=row.counted.last_seen_at,
                )
                for row in rows
            ],
            page=OffsetPageInfo(offset=page.offset, limit=page.limit, total=total),
            meta=sources_meta(now, query, engines, whole),
        )

class PageCount:
    url_id: int
    url: str
    host: str
    registrable_domain: str
    title: str | None
    domain_role: str
    role_entity_id: UUID | None

async def page_counts(
    db: AsyncSession,
    scope: SourceScope,
    *,
    roles: Sequence[str] | None,
    registrable_domain: str | None,
    sort: str,
    offset: int,
    limit: int,
) -> tuple[list[PageCount], int]:
    """A page of sources by (page, role, entity), and how many there are. The title is the
    greatest one an answer gave the page (any one, the same on every read)."""
    answers, source = _cited(scope)
    u = urls.c
    keys = (
        _C.url_id,
        u.canonical_url,
        _D.host,
        _D.registrable_domain,
        _C.domain_role,
        _C.role_entity_id,
    )
    grouped = (
        select(*keys, func.max(_C.title).label("title"), *_measures(answers, scope))
        .select_from(source.join(urls, u.id == _C.url_id))
        .where(*citation_bounds(scope))
        .group_by(*keys)
    )
    if roles:
        grouped = grouped.where(_C.domain_role.in_(list(roles)))
    if registrable_domain is not None:
        grouped = grouped.where(_D.registrable_domain == registrable_domain)
    rows, total = await page_of(
        db,
        grouped,
        order_by(
            sort, u.canonical_url, _C.url_id, _C.domain_role, _C.role_entity_id.asc().nulls_first()
        ),
        offset=offset,
        limit=limit,
    )
    return [
        PageCount(
            url_id=row.url_id,
            url=row.canonical_url,
            host=row.host,

        .where(*citation_bounds(scope))
    )

    if given.registrable_domain is not None:

    if given.url_id is not None:
        statement = statement.where(_C.url_id == given.url_id)
    if after is not None:

        statement = statement.where(
            or_(
                _C.observed_at < at,
                and_(_C.observed_at == at, _C.observation_id < observation_id),
                and_(
                    _C.observed_at == at,
                    _C.observation_id == observation_id,
                    _C.citation_index > index,
                ),
            )
        )
    statement = statement.order_by(
        _C.observed_at.desc(), _C.observation_id.desc(), _C.citation_index

def _stored_list(answers: Any) -> Any:

    return case(

        else_=literal_column("'[]'::jsonb"),
    )


def _issued(scope: SourceScope) -> Any:
    """One row per query a counted answer stored, with its normalized text computed here, so
    the outer query groups by a plain column (a bound parameter in a GROUP BY expression is a
    new parameter at each use)."""
    answers = counted_answers(scope)
    queries = (
        func.jsonb_array_elements_text(_stored_list(answers)).table_valued("value").lateral("queries")
    )
    normalized = func.lower(func.btrim(func.regexp_replace(queries.c.value, r"\s+", " ", "g")))
    return (
        select(
            answers.c.observation_id,
            answers.c.observed_at,
            answers.c.prompt_id,
            answers.c.engine_code,
            queries.c.value.label("query_text"),
            normalized.label("normalized_text"),
        )
        .select_from(answers.join(queries, true()))
        .subquery("issued")
    )


async def fanout_counts(
    db: AsyncSession, scope: SourceScope, *, min_support: int, offset: int, limit: int
) -> tuple[list[FanoutCount], int]:
    """A page of queries by (normalized text, engine), the most issued first, and how many
    there are. A query an answer lists twice counts once for it."""
    issued = _issued(scope)
    observations = func.count(issued.c.observation_id.distinct())
    grouped = (
        select(
            issued.c.normalized_text,
            issued.c.engine_code,
            func.mode().within_group(issued.c.query_text).label("query_text"),
            observations.label("observations"),
            func.count(issued.c.prompt_id.distinct()).label("prompts"),
            func.array_agg(issued.c.prompt_id.distinct()).label("prompt_ids"),
            func.min(issued.c.observed_at).label("first_seen_at"),
            func.max(issued.c.observed_at).label("last_seen_at"),
        )
        .where(issued.c.normalized_text != "")
        .group_by(issued.c.normalized_text, issued.c.engine_code)
        .having(observations >= min_support)
    )
    rows, total = await page_of(
        db,
        grouped,
        [desc(literal_column("observations")), issued.c.normalized_text, issued.c.engine_code],
        offset=offset,
        limit=limit,
    )
    return [
        FanoutCount(
            normalized_text=row.normalized_text,
            engine_code=row.engine_code,
            query_text=row.query_text,
            observations=row.observations,
            prompts=row.prompts,
            prompt_ids=tuple(sorted(UUID(str(value)) for value in row.prompt_ids)),
            first_seen_at=row.first_seen_at,
            last_seen_at=row.last_seen_at,
        )
        for row in rows
    ], total


async def fanout_cited(
    db: AsyncSession, scope: SourceScope, keys: Sequence[tuple[str, str]], *, top: int
) -> dict[tuple[str, str], list[CitedDomain]]:
    """For each (normalized text, engine), the `top` registrable domains with the most citation
    units in the answers that issued it, most first, then by name."""
    if not keys:
        return {}
    issued = _issued(scope)
    pairs = (
        select(
            issued.c.observation_id,
            issued.c.observed_at,
            issued.c.normalized_text,
            issued.c.engine_code,
        )
        .where(tuple_(issued.c.normalized_text, issued.c.engine_code).in_(list(keys)))
        .distinct()
        .subquery("pairs")
    )
    grouped = (
        select(
            pairs.c.normalized_text,
            pairs.c.engine_code,
            _D.registrable_domain,
            _C.domain_role,
            _C.role_entity_id,
            func.count(unit()).label("units"),
        )
        .select_from(
            pairs.join(
                ai_citations,
                and_(
                    _C.observation_id == pairs.c.observation_id,
                    _C.observed_at == pairs.c.observed_at,
                ),
            ).join(domains, _D.id == _C.domain_id)
        )
        .where(*citation_bounds(scope))
        .group_by(
            pairs.c.normalized_text,
            pairs.c.engine_code,
            _D.registrable_domain,
            _C.domain_role,
            _C.role_entity_id,
        )
        .subquery("grouped")
    )
    ranked = select(
        grouped,
        func.row_number()
        .over(
            partition_by=(grouped.c.normalized_text, grouped.c.engine_code),
            order_by=(
                grouped.c.units.desc(),
                grouped.c.registrable_domain,
                grouped.c.domain_role,
                grouped.c.role_entity_id.asc().nulls_first(),
            ),
        )
        .label("place"),
    ).subquery("ranked")
    rows = await db.execute(
        select(ranked)
        .where(ranked.c.place <= top)
        .order_by(ranked.c.normalized_text, ranked.c.engine_code, ranked.c.place)
    )
    found: dict[tuple[str, str], list[CitedDomain]] = {}
    for row in rows:
        found.setdefault((row.normalized_text, row.engine_code), []).append(
            CitedDomain(
                registrable_domain=row.registrable_domain,
                domain_role=row.domain_role,
                role_entity_id=row.role_entity_id,
                citation_units=row.units,
            )
        )
    return found


async def fanout_totals(db: AsyncSession, scope: SourceScope) -> FanoutTotals:
    """The counted answers, those that issued a query (docs/16 F1) and those whose stored list
    is shorter than what they issued: a list is complete exactly when its length is the
    answer's `fanout_count` (the `truncated` flag is also set when only another list was cut)."""
    answers = counted_answers(scope)
    stored = case(
        (
            func.jsonb_typeof(answers.c.fan_out) == "array",
            func.jsonb_array_length(answers.c.fan_out),
        ),
        else_=0,
    )
    row = (
        await db.execute(
            select(
                func.count().label("answers"),
                func.count().filter(answers.c.fanout_count > 0).label("with_fanout"),
                func.count().filter(stored < answers.c.fanout_count).label("truncated"),
            ).select_from(answers)
        )
    ).one()
    return FanoutTotals(
        answers=row.answers, answers_with_fanout=row.with_fanout, answers_truncated=row.truncated
    )
```

def _left_out(
    skipped: Sequence[Skipped], pending: set[tuple[UUID, str]], engines: Sequence[str]
) -> list[Skip]:
    """What a bulk run leaves out and why, by prompt and engine: the planner's own skips, and
    every asked engine of a prompt with an answer on its way, `check_pending` where it is pending
    and `prompt_pending` on its other engines (a run's selector asks every prompt it names on
    every engine it names, so such a prompt cannot be asked on some engines only)."""
    reasons: dict[tuple[UUID, str], str] = {
        (item.prompt_id, item.engine_code): item.reason for item in skipped
    }
    for prompt_id in {prompt for prompt, _ in pending}:
        for code in engines:
            if (prompt_id, code) in pending:
                reasons[(prompt_id, code)] = "check_pending"
            else:
                reasons.setdefault((prompt_id, code), "prompt_pending")
    return [
        Skip(prompt_id, code, reason)
        for (prompt_id, code), reason in sorted(
            reasons.items(), key=lambda item: (str(item[0][0]), item[0][1])
        )
    ]

async def lock_prompts(
    db: AsyncSession, workspace_id: UUID, project_id: UUID, ids: Sequence[UUID]
) -> dict[UUID, bool]:
    """The project's live prompts among `ids`, each with whether it is active, held (FOR NO KEY
    UPDATE) until the transaction ends, taken in id order so two writers never wait on each
    other in a circle."""
    p = ai_prompts.c
    rows = await db.execute(
        select(p.id, p.is_active)
        .where(
            p.workspace_id == workspace_id,
            p.project_id == project_id,
            p.deleted_at.is_(None),
            among_ids(p.id, ids),
        )
        .order_by(p.id)
        .with_for_update(key_share=True)
    )
    return {row.id: row.is_active for row in rows}


async def set_active(

    await db.execute(
        update(ai_prompts)
        .where(ai_prompts.c.workspace_id == workspace_id, among_ids(ai_prompts.c.id, ids))
        .values(is_active=is_active, updated_at=now)
    )

```python
    async def bulk_archive(
        self, access: WorkspaceAccess, project_id: UUID, body: PromptBulkArchive, info: RequestInfo
    ) -> tuple[int, int]:
        """Archives or brings back the given prompts as `archive` and `PATCH is_active` do one:
        answers, versions and terms stay, and a prompt brought back is not checked against the
        engines' countries again. Ids the project does not have are not matched. Bringing back
        counts against the active prompt quota, all or none. How many matched and how many
        changed."""
        async with self._transaction(access) as db:
            await live_project(db, access, project_id)
            if not body.archive:
                # Same order as create and PATCH: the workspace lock, then the prompt rows.
                await prompts.lock_prompt_writes(db, access.workspace_id)
            found = await prompts.lock_prompts(
                db, access.workspace_id, project_id, sorted(set(body.ids))
            )
            changing = [prompt_id for prompt_id, active in found.items() if active == body.archive]
            if changing and not body.archive:
                limit, used = await prompts.quota_usage(db, access.workspace_id)
                if used + len(changing) > limit:
                    raise quota_error(limit, used, len(changing))
            await prompts.set_active(
                db, access.workspace_id, changing, not body.archive, datetime.now(UTC)
            )
            await audit.record(
                db,
                workspace_id=access.workspace_id,
                actor_id=access.user_id,
                action="prompt.bulk_changed",
                target_type="project",
                target_id=project_id,
                info=info,
                after={
                    "is_active": not body.archive,
                    "matched": len(found),
                    "changed": len(changing),
                },
            )
            await audit.record_each(
                db,
                workspace_id=access.workspace_id,
                actor_id=access.user_id,
                action="prompt.archived" if body.archive else "prompt.updated",
                target_type="prompt",
                info=info,
                entries=[
                    audit.Entry(
                        target_id=prompt_id,
                        before={"is_active": body.archive},
                        after={"is_active": not body.archive, "bulk": True},
                    )
                    for prompt_id in changing
                ],
            )
        return len(found), len(changing)
```
