## 3. Risks

1. **The 276 day read.** `kind=lost` reads 3 windows (3 x 28 = 84 days by default, 276 days for a 92 day ask). The page already asks for it twice (new and lost counts) with `limit: 1`. T2 makes the strip and the tab one query key (`limit: 100`), `staleTime` 5 minutes, no focus refetch, and says on the Lost list how many days it reads. The mock has 92 days of history, so Lost is empty for any window over about 30 days; the fixtures target the default 28 days (T1).
2. **Fixture swaps move row counts.** The overlay keeps every total (it swaps one citation for another in the same answer) but lowers the `example.com` row. Tests and e2e that read that row's units change. T1 runs the baseline of `citations-model.test.ts`, `citations.test.ts`, `citations-screen.test.tsx`, `domains-tab.test.tsx`, `pages-tab.test.tsx` and `e2e/flows/ai-citations.spec.ts` assertions first and lists what moved.
3. **Contradictions with the brief.** (a) "RefetchBar" does not exist (F13). (b) J and K step "over table rows" but the inspector ignores a treegrid (F7). (c) The flag toggles "apply to reads", but the citations list route refuses them (F3). (d) WB-SRC-03 asks for the marker focused in the evidence viewer; the viewer is WP-26's, so only the link and the `cite` hint land (F12). (e) WB-NAV-08 names four pages; three do not exist (F14). (f) WB-DOM-06 has no read behind it (F11). (g) `citation-details.ts` says it serves series, lost and cited-with; `citations.ts` already does.
4. **Group rows cannot open an inspector** (F6): deviation from DS 9.7, recorded; an optional shared prop `onGroupRowOpen` on `DataTable` would fix it later.
5. **No read of one URL** (F10): a source opened by a shared link needs both reads; when the page is outside the 200 most cited pages of its domain the strip says n/a with the reason.
6. **Prompt engines are joined** (F9): the engine of each prompt of a domain comes from the latest 100 citations of that domain; a prompt not in them says "n/a" with the reason, never an empty cell.
7. **Country choices** come from the first 200 prompts (`promptTextsQuery`); a link's country is always kept.
8. **`include_engine_internal` changes no number** until ingest sets the flag (contract O10): said in the As built note, not hidden.
9. **Saved view.** `kind`, `redirects` and `internal` become view keys (so "Default (edited)" shows when one is set); `country` is scope and is not. A "New sources" preset is left out (D14 of WP-21 said it waits for this tab; it is cheap but changes the view tests; the coordinator may ask for it).
10. **Heavy reads in tests.** The tab tests must count requests (the `watch()` pattern of `citations-screen.test.tsx`) to prove no refetch storm.
