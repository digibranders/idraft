# Visual Reference Screens

Status: Accepted (design-system v2 visual source)
Last updated: 2026-09-29

Seven high-fidelity screens that define how the product looks. Design-system v2 takes its colors, type, sizes, spacing and component styling from them. Each visual observation is turned into a value in [visual-spec.md](visual-spec.md), and documents 00 to 27 follow that file.

**Precedence.** For appearance, the screens (through visual-spec.md) are the source of truth. For product and data rules (navigation structure, inspector content, when a delta is colored, denominators, unknown values, accessibility), documents 00 to 27 win. The images were generated by an image model, so they also contain some layout, data and wording mistakes. Section 3 lists the ones not to copy.

## 1. How the set was made

- Generated with ChatGPT image generation on 2026-09-29, one screen per request, 1536 x 1024 px each.
- The brief was written from the v1 tokens and rules of the time: canvas `#F9FAFB`, cobalt accent `#2763D7` and nothing else, Geist, 13 px base, hairline borders, a metric strip instead of KPI cards, neutral badges, and no shadows on panels ([generation-brief.md](generation-brief.md)).
- Product name "Sightline" and domain "fieldnote.io" are placeholders. The data is illustrative only.
- An earlier set (a product called "BrandLens") was studied and rejected. It had a saturated indigo accent, multicolored pills, KPI cards with tinted icon tiles, and a donut chart. Only its layout ideas carried over.

### What the whole set gets right

These are the qualities to match on every screen:

1. **One accent, used sparingly.** Cobalt appears on the current nav item, the primary button, the active tab, the selected segment, links, the selected row, checked controls and the own-brand series. Nowhere else.
2. **Numbers carry the page.** Metric values are the largest text after the page title. Tables right-align tabular figures, and labels stay gray and small.
3. **Hairlines, not boxes.** Panels have a 1 px border and 8 px radius and no shadow. Tables have horizontal dividers only.
4. **Real data starts high.** The page title, metric strip and first chart or table all fit in the first 300 px below the top bar.
5. **Quiet categories.** Intent, topic and type badges are small gray rectangles. Green and red appear only on values that changed.
6. **The same shell everywhere.** The sidebar, top bar (search with ⌘K, date range, location), page header and filter bar are identical across screens.

## 3. What not to copy (product and data rules win)

These are content, structure or data mistakes in the images. Their visual styling is still the reference; only the listed behavior differs.

| Where | The image shows | Build this instead |
|---|---|---|
| All screens, sidebar | Pages named "SERP features", "Engines" and "Changes" | The information architecture in [11-navigation.md](../11-navigation.md) section 1 (Overview, Matrix, SEO, AI Visibility, Competitors, Topics, Discover, Reports, Integrations, Settings), styled exactly as the images show |
| 1 | A 7d, 28d, 90d period segmented control in the page header | Nothing in the page header: the date window has one control, the `DateRangePicker` in the top bar ([11-navigation.md](../11-navigation.md) section 4). The segmented styling applies to other segmented controls (density, device, status) |
| 1 | No-change values drawn as a dash glyph | `0` or `0 pts` in neutral ([14-badges-status.md](../14-badges-status.md) section 5) |
| 1, 4, 5 | Rates without denominators or sample sizes | `k of n` and intervals wherever the metric contract requires them ([23-application-patterns.md](../23-application-patterns.md) section 8) |
| 2, 7 | Every rank change colored green or red | Color only when the change is emphasized, via `formatRankChange` ([14-badges-status.md](../14-badges-status.md) section 5) |
| 2 | Keyword inspector tabs Overview, SERP, AI answers, History | Overview, SERP, AI, Timeline ([23-application-patterns.md](../23-application-patterns.md) section 4.2) |
| 3 | "Mention order 0" for an engine that did not mention the brand | `n/a` ([22-content-formatting.md](../22-content-formatting.md) section 2) |
| 4 | Prompt inspector tabs named after engines (ChatGPT, Gemini, AI Mode, AI Overview) | The 440 px wide inspector as shown, with the tabs Latest, History, Citations, Competitors, Stats; the Latest tab shows a `ResponsePreview` per engine ([23-application-patterns.md](../23-application-patterns.md) section 4.2) |
| 5 | The "Media" segment in cobalt | Cobalt (`chart-1`) is reserved for the own brand; other segments follow the chart palette order ([15-data-visualization.md](../15-data-visualization.md)) |
| 6 | A standalone "Changes" page with an alert-rules column | No such page in V1. The screen's styling (day panels, 36 px event rows, CountTabs, rule list) is the style for `ChangeFeed` on Overview, `EventTimeline` in inspectors and detail pages, and alert rules in Settings ([18-notifications-alerts.md](../18-notifications-alerts.md)) |
| All | Badges like "topic" and "intent" repeated as text | Show the real category value (for example "Commercial"), never the category name |

Generate a brand new image, do not edit a previous one." Save each result here as `sightline-NN-name.png` and add a row to sections 2 and 3.
